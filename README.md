# 手写试卷全链路 · handwritten-paper-transcribe

**把学生做过、教师批改过的手写试卷照片，一路做成干净可编辑的转录稿，再出成学生版与教师版 PDF。**

手机拍的手写试卷（满页红蓝手写）直接喂 OCR，**手写会被当成题目内容**，识别结果一团糟。
这个项目先把手写擦掉、拿到干净版面再转录，然后逐题对照原图把丢失与误识别补回来，
最后把题解出来、出成两版可打印 PDF。

仓库里有一个可被 Codex / Claude Code 等 agent 直接使用的技能
（[`skills/handwritten-paper-transcribe/`](skills/handwritten-paper-transcribe/SKILL.md)），
以及两个真实高三试卷案例的完整产出与复现步骤。

## 这条链路的两条核心经验

都是 2026 年 10 月在真实手写试卷上一刀一刀踩出来的：

1. **去手写版是更好的转录源，但手写压印过的印刷字会被擦糊** —— 那几处必须回原图 + 用数学反推双验。
   实证：某题椭圆方程被手写完全盖死，靠"若 $\frac{x^2}{4}+\frac{y^2}{3}=1$ 则与 $y^2=4x$ 交于 $x=\frac23$，
   得 $|AB|=\frac{4}{3}\sqrt6$ 正合选项 B"一击锁定，比对着糊图猜可靠得多。
2. **去手写会把学生填进"印刷空格 / 横线作答处"的答案一并擦掉** ——
   凡印刷体留空、横线、`______` 的位置，**必须回原图看学生填了什么**。
   实证：某卷解答题第 (1) 问，学生手写的 $(-\infty,+\infty)$ 被去手写版整个擦没，只看干净版既读不出答案、还会误判"原卷漏印"。

## 九步流程

```
0 拿图 → 1 去手写 → 2 合 PDF → 3 MinerU 转录 → 4 图形核对
→ 5 逐题对照原图校对润色 → 6 落盘自检 → 7 解题与数值自验 → 8 出片（学生版/教师版） → 9 交付
```

| 步 | 做什么 | 本仓库提供的工具 |
|---|---|---|
| 1 | 手写擦除（扫描全能王 `image enhance --mode 9`） | 走 `camscanner` 官方 CLI |
| 2 | 图片按页序合成 PDF | `scripts/images_to_pdf.py` |
| 3 | MinerU 转录（`--model vlm`） | MinerU CLI |
| 4 | 图形引用与磁盘一一对应 | `scripts/check_transcribe.py` |
| 5 | 逐题回原图校对；窄区放大**两步定位法** | `scripts/crop_zoom.py`（`--grid` 叠比例网格定位） |
| 6 | 转录稿自检（`$` 配对 / `$$` 偶数 / 图片引用） | `scripts/check_transcribe.py` |
| 7 | 解全部题；难题写脚本数值复算 | 见案例目录 |
| 8 | 出学生版（题面 + 作答留白）/ 教师版（答案 + 完整解析） | `scripts/make_student_md.py` + [`math-handout-pdf`](https://github.com/cheng-bai) 出片链 |
| 9 | 交付与呈递 | — |

## 复现

完整步骤、命令与**可量化的验证指标**见 **[`docs/复现指南.md`](docs/复现指南.md)**。

依赖：扫描全能王 CLI（去手写）、MinerU CLI（转录）、带 Pillow / numpy 的 Python，
出片另需 [`math-handout-pdf`](https://github.com/cheng-bai) 技能。两个 CLI 都不在 PATH，请写绝对路径。

> 本仓库**不含**原始试卷照片、去手写图与逐题校对裁图 —— 那些材料上有学生手写笔迹，为保护隐私刻意排除。
> 因此第 0～2 步请自备自己的试卷照片；只想验证方法的话，可以拿 `mineru-原始输出/` 当起点。

## 已知限制

- 案例A 某解答题第 (1) 问：原卷印刷体在"在区间"与"上的"之间**无区间记号**（疑似原卷漏印，10× 放大确认无墨迹）。
  转录稿按原样保留、未擅自补，教师版里标为**待核**。
- 案例B 的转录稿 frontmatter 曾被外部工具改动（写成转义形式 `\---`，`title` 与正文 H1 不一致），**原样保留** ——
  它正好是"转录稿被别的工具动过"的真实样本，也是学生版脚本要兼容 `\---` 的原因。
- 去手写是**云端服务**，输入图片会上传服务端；含学生姓名 / 学号的卷子请**先裁掉或打码**。
