## 三、技能缺陷清单（本次最重要产出）

> 说明：SKILL 整体质量高、可照做。以下为**与实测不符 / 未预警 / 表述含糊**之处，具体到句与步。

### A. 说明书**未预警**的坑（实际踩到）

1. **【第5步】"只裁疑点那十几个字符"缺少定位方法** —— SKILL 只给了 `crop_zoom.py --box 0.34,0.390,…` 的示例，但**没说怎么先找到疑点在图里的比例坐标**。我前 6–8 刀全裁偏（横带位置估错），靠"先裁一条**宽横带**定位行、再窄裁放大"的两步法才找到节奏，共裁约 20 次。建议 SKILL 补一句两段定位法。
2. **【错型清单】缺"向量记号：上横线 ↔ 箭头"整类** —— `references/mineru-math-error-catalog.md` 的符号误识别表里**没有**这一类。本题第 10 题（`\overrightarrow`→`\overline`）、第 16 题（`\vec`→`\bar`，且**同题内先 `\bar` 后 `\vec` 自相矛盾**）都是这个坑。且"同一题内记号不一致"是比"读错"更隐蔽的信号，值得单列。
3. **【错型清单】缺"上标负号被吞 + 无端加上横线"** —— 第13题 MinerU 把 `x^{-\frac32}` 识别成 `\bar{x}^{\frac32}`：**负号丢了、还凭空加了个 `\bar`**。catalog 有"分式整体崩坏""关系符被吃掉"，但没有"指数负号丢失"。
4. **【错型清单】缺"无端加粗 / 字母升格"** —— 第20(2) 把普通 `y` 识别成 `\pmb{y}`；第19(3) 把普通正体 `N` 升格成 `\mathbb{N}`。catalog 只提了"花体混入 `\mathrm{e}`→`\mathfrak{e}`"一种，**方向相反的另一类（凭空加粗体、凭空升格集合符号）没有覆盖**。
5. **【第6步 / catalog 第五节】自检脚本"跳过代码块"的边界没说清** —— SKILL 写"`$` 定界符配对（**跳过代码块**）"。实测：脚本（`check_transcribe.py:35`）**只按行首 ``` 判定 fenced code block**，**行内反引号 `code` 里的 `$` / `$$` 照样计数**。我在【转录与校对说明】表里写了一句 `` `$$ … $$` `` 描述第18题，脚本就把这 2 个 `$$` 计进了"`$$` 块配对"。本次恰因成对（2 个，偶数）没报错；**若只写一个 `$$` 就会误报 FAIL**。catalog 第五节只预警了"反引号内 LaTeX 被误报为裸露 LaTeX"（指 `$`），**没预警 `$$` 也会被计数、也没点明"跳过"仅限 fenced block**。

### B. 说明书**表述含糊、需要自己拍板**的地方

6. **【第6步】md 结构没规定"大题标题 vs 题号"的层级关系** —— SKILL 示例给的是 `## 一、填空题：` + 题号加粗 `**1.**`，但**没说**：(a) 解答题大题标题（`## 三、解答题…`）与其中的题号（`**17.**`）如何共存；(b) **MinerU 会把个别解答题题号误升为 `## 18.`（H2）**，须手工降级。这条是我自己判断补的，说明书无据。
7. **【第6步】大题标题是否保留原卷完整说明没规定** —— 原卷大题标题含"（本大题共有12题，满分54分，第1~6题每题4分…）"一大段，SKILL 示例只写"`## 一、填空题：`"。我选择**保留原卷全文**（遵从"逐字保留"），但这是猜的。
8. **【第5步】选择题"题干与选项是否另起一行"没规定** —— MinerU 把 13/14/15/16 的题干与选项挤在一行，处置方式靠自己定。
9. **【第5步】填空"作答横线"的写法和长度没规定** —— SKILL 只说"补回缺失的作答横线"，没给统一符号（我用 `\_\_\_\_`）。原卷横线长度不一，是否统一也不明。
10. **【前置检查 / 第3步】各脚本该用哪个 python 未在"参考"节标明** —— `images_to_pdf.py`、`crop_zoom.py` 都依赖 Pillow，MinerU 是独立 CLI。SKILL 正文零散提了托管 python 路径，但"参考"节没给"哪个脚本 + 哪个解释器"的对照，需要自己拼。

### C. 轻微 / 建议

11. **【第0步】未提剪贴板目录可读** —— SKILL 只预警微信 `~/Library/Containers/...` 读不了。本次输入在 `~/.workbuddy/clipboard-images/`，**可正常读**，建议补一句"剪贴板图片目录通常可读"。
12. **【第7步】把 `math-handout-pdf` 的出片参数抄进了本技能** —— 留白经验值、`fig_width: 23%` 等一堆参数写死在本技能内，两处维护易失同步；建议改为"见 `math-handout-pdf`"引用。（本次未走出片，无法验证参数本身。）
13. **【第1步】`-o` 输出目录若不存在是否自动创建未说明** —— 我预先 `mkdir -p`，没验证不存在时会怎样。
