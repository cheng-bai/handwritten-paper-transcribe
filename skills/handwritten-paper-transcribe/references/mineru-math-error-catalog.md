# MinerU 中学数学卷转录高频错型清单

转录后**逐题对照原图**时按下表排查。括号内是 2026-10-12 那份高三卷（去手写版）的实测实例。

## 一、结构性丢失（最隐蔽，必须逐题比对）

| 错型 | 表现 | 处理 |
|---|---|---|
| **题号丢失** | 首题或中间某题的 `1.` / `7.` 整段消失，正文直接从"已知…"开始（实测：第 1、7 题） | 按题序补回题号 |
| **选项末位被吞** | 选择题只到 `C.`，`D.` 整条丢失（实测：第 14 题 D"严格减的偶函数"被吞） | 回原图补；若原卷解析/答案部分重印了同题，可两处交叉补 |
| **整句消失** | 题干中"则这组数据…"整句没了，或只剩一个孤立符号块 | 回原图补整句，删掉孤立块 |
| **作答横线被吞** | 填空题失掉末尾 `____`（实测：第 5 题） | 按填空题惯例补 `\_\_\_\_` |
| **图注/标号错位** | "图1"跑到图片引用之前，或标号在图上方 | 原卷标号多在**图下方**，按序归位 |
| **跨页表格丢行** | 表格跨页时下一页顶部整行未转录 | 从原图补；用解析里的均值/总数反推验证 |

## 二、符号与字符误识别（一字之差，答案全变）

| 错型 | 实测实例 | 判据 |
|---|---|---|
| 关系符被吃掉 | 第 1 题 `M = {-1,1,3}` → `M \neq {-1,1,3}`；`{x \mid y=√(1-x)}` → `;x, y = \sqrt{1-x};` | 集合条件必须是等式，`\neq` 讲不通 |
| 字母形近 | 第 4 题准线 `x = -1` → `\alpha = -1`；第 10 题 `\frac{9}{x}` → `\frac{y}{x}` | 看数学语境：准线方程的自变量、分式分子的量级 |
| 下标形近 | 第 11 题 `F_2` → `F_1`（**两处都错**） | 放大原图逐字看下标；本题"中垂线经过点 $F_2$，且点 $F_2$ 到直线 $l$" |
| 下标被凭空加上 | 第 9 题 `{x \mid |x-a|<3}` → `{x_i \mid |x-a_i < 3}` | 集合描述的对象是 $x$，不该有下标 $i$ |
| 绝对值竖线丢失 | 同上，`|x-a|` 的右竖线没了 | 补回 `\lvert \rvert` |
| 汉字形近 | 第 8 题"则此次考试" → "到此次考试"；第 14 题"严格**增**的偶函数" → "严格**着**的偶函数" | 放大到 3~4 倍逐字确认 |
| 分式整体崩坏 | 第 15 题 `\frac{x^2}{4}+\frac{y^2}{3}=1` → `\frac{y}{3}+\frac{y}{3}=1` | **用选项反推**（见下） |
| 花体混入 | 第 21 题 `\mathrm{e}` → `\mathfrak{e}` | 统一为 `\mathrm{e}` |
| **向量上横线 ↔ 箭头（整类）** | 第 10 题 $\overrightarrow{AC}\cdot\overrightarrow{BE}$ 被转成 `\bar{AC}\cdot\bar{BE}` 或 `\vec{AC}`；同一题里两种写法混用 | **原卷记号为准**：中学卷向量通常写 $\overrightarrow{AB}$（箭头）。**同题内记号自相矛盾**是比读错更隐蔽的信号——$\overrightarrow{AB}$ 与 $\bar{AB}$ 不会同时出现在同一份卷里，看到混用就说明至少一处是识别错。逐题统一到原卷那一种。 |
| **指数负号被吞 + 无端加上横线** | 第 13 题 $x^{-\frac32}$ 被转成 `\bar{x}^{\frac32}`（**负号丢了**，又**凭空给 $x$ 加了横线**） | 两个错叠在一起，只按"看起来像啥"改会越改越错。回原图逐字看**指数上的符号**与**底数有没有横线**：负指数（递减）与正指数（递增）反了，单调性整题作废。 |
| **凭空加粗 / 字母升格** | 第 19(3) 普通正体 $N$ 被转成 `\mathbb{N}`（数集符号）；个别 $y$ 被转成 `\pmb{y}` | **中学卷里的普通变量不会写成黑体 $\mathbb{}$（那是 $\mathbb{N,Z,Q,R}$ 数集专用）**，也不会随便加粗。默认去粗、去 `\mathbb`，除非原卷确实是数集符号。 |
| 数学符号 | `∥`→`//`、`△`→`Δ`、`\ln`→`ln`、`h''(x)`→`h²(x)`、`\log_{1/2}x`→`\log\frac12x` | 按数学上下文改正 |

## 三、"两版都读不出"时的三条出路

被手写盖死的位置，去手写版擦糊、原图被压住，谁都看不清。按可靠性从高到低：

1. **用题面其他条件/选项反推**（最可靠）
   实例：第 15 题椭圆方程两版都读不出。已知选项含 $\frac{4}{3}\sqrt6$ → 试 $x^2/4+y^2/3=1$，与 $y^2=4x$ 交于 $x=2/3$，得 $|AB|=\frac{4}{3}\sqrt6$ **正合选项 B** → 方程锁定。
2. **借同一知识点的其他印次** —— 若卷末解析部分重印了题干，两处比对。
3. **标"待核"** —— 写进 md 末尾【待核事项】表格，写明"本稿按 X 转录；若实际为 Y，结论/答案会怎么变"。**绝不许猜一个值当确定值填进去。**

实例：第 7 题 $\vec b$ 首分量被手写压死（读不出有无负号）→ 标待核，并写明"若为 $(-1,1)$，投影向量由 $(\frac52,\frac52)$ 变为 $(\frac12,-\frac12)$"。

## 三·补、印刷作答空处：**干净版会漏信息**（v1.2.0 新增）

去手写版把"手写"当噪声一律擦除 —— 于是**学生填进印刷空格 / 横线 / 括号作答位的答案，也一起被擦掉**。转录链基于干净版，光看它会：

- 误判"原卷此处漏印"（其实印刷体确实留空，但学生在上方写了东西）；
- 丢掉"学生填了什么"这条对于错因分析 / 学情了解极有用的线索。

**硬规则**：凡印刷体留空、横线、`______`、括号作答位，**一律回原图看**。实例：

> 向明卷第 21(1)「与 $y=-x^2+4x$ 在区间　上的"分割函数"」—— 原卷印刷体在"在区间"与"上的"间**只留约半字空白、无区间记号**；但**原图空白正上方有学生手写的 $(-\infty,+\infty)$**，去手写版把它整个擦没了。结论：**"原卷是否真的漏印记号"与"学生填没填"是两件事**，只有原图能同时回答。

## 四、校对操作要点

- **放大只能裁窄区**：输出宽上限 ~1400 px，全宽裁剪等于没放大。要看清一个字就只裁那十几个字符。
- **两步定位法（v1.2.0）**：先用 `crop_zoom.py --grid` 在整图叠 0.05/0.1 比例网格，读出疑点所在**横带**的 $y$ 范围，再按该带 `--box` 窄裁放大。**别凭感觉盲试 `--box`**（实测量级：一个子 Agent 偏了约 20 次）。
- **双源对照**：去手写版读正文，原图读被压印处的残影，**也读学生填进印刷作答空处的答案**。
- **印刷作答空处必回原图**：留空 / 横线 / `______` / 括号作答位，干净版一律是空的 → 只看它既读不出学生答案、又会误判"原卷漏印"。原图才分得清"印刷体有没有印记号"与"学生填了什么"两件事。
- **统计图读数必须程序化测量**，不要目视读柱高（目视极易串位）。
- **原卷自身笔误 ≠ 识别错误**：先放大到原图逐字确认，是原卷写错就在正文订正并注明"原卷作 X，应为 Y，已核非转录致误"。

## 五、交付前自检

```bash
python scripts/check_transcribe.py "<转录稿.md>"
```

- `$` 定界符全部成对（跳过 fenced 代码块 **与行内反引号**）
- `$$` 出现偶数次（同样跳过代码块与行内反引号）
- 图片引用可达、且 `images/` 无孤儿

**注意（v1.2.0 已修）**：`check_transcribe.py` 现在会把**行内反引号 `` `...` `` 内的内容整段剥掉**再计数——所以在校对说明里引用 MinerU 原始输出（如 `` `M \neq {-1,1,3}` ``、`` `$$` ``）不会误报。若仍见"裸露 LaTeX"告警，那是**代码块外的真裸露**，照常修。旧版本只认行首 fenced block、行内反引号会照样计数（`$$` 单写一个就误报 FAIL）；如遇到老脚本，记得先升级。
